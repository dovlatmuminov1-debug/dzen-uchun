## ★ ЯДРО ПЕРСОНАЖА (заполнить внутри — в выдачу не входит)

ПРОТАГОНИСТ: [одна уникальная привычка — только его/её]
АНТАГОНИСТ: [его собственная логика — он тоже прав]
ГЛАВНОЕ НЕПОНИМАНИЕ: [разница в восприятии мира, не в словах]
РЕЧЬ ПРОТАГОНИСТА: [короткая/длинная, прямая/обходная]
РЕЧЬ АНТАГОНИСТА: [как защищается, как атакует]

**Правила:**
— Оба правы в своём мире. Один явно виноват → переписать.
— Конфликт — столкновение двух способов выживать, не злодейство.
— Мужской персонаж: минимум в 1 сцене принимает решение и отстаивает его. Его молчание — позиция, не пустота. Он тоже что-то теряет — показать явно.

**ТЕСТ:** Убери мужского персонажа — конфликт изменится? НЕТ → переписать.

## ХУК — АБСОЛЮТНОЕ ТРЕБОВАНИЕ

Первые 2 предложения — захват без предупреждения.
Никакого вступления, места, погоды, представления. Сразу — удар.

**ТИПЫ ХУКА (выбрать один):**

ТИП 1 — ФАКТ + ТАЙНА: «Каждое утро ставила два стакана. Пила только из одного.»
ТИП 2 — ФИНАЛ ВПЕРЁД: «Он ушёл тихо. Она не удивилась.»
ТИП 3 — ДЕЙСТВИЕ + НЕЛОГИЧНАЯ ДЕТАЛЬ: «Приготовила завтрак на двоих. Хотя уже год жила одна.»
ТИП 4 — ДИАЛОГ С СЕРЕДИНЫ: «— Ты давно это знала? Она не ответила.»
ТИП 5 — ВИЗУАЛ + ХОЛОДНЫЙ ФАКТ: «На столе стояло два стакана. Двенадцать лет подряд.»

Предательство → ТИП 2/3. Одиночество → ТИП 1/5. Конфликт → ТИП 4. Потеря → ТИП 1/2.

**ТЕСТ ХУКА — все три ДА:**
□ Возникает вопрос?
□ Есть необъяснённая деталь?
□ Есть эмоциональное давление?

## СТИЛЬ И РИТМ

Каждая сцена должна создавать давление — не каждое предложение.
Дай читателю дышать между ударами. Напряжение копится — не бьёт непрерывно.

**Эмоции:** избегай прямого называния чувств, если жест сильнее.
Иногда одно слово точнее длинного описания — используй по ситуации.

Предпочтительно:
❌ «она была расстроена» → ✅ «дважды перемыла одну и ту же тарелку»
❌ «он злился» → ✅ «открыл холодильник, закрыл, снова открыл»

Допустимо: «Она поняла.» — если это сильнее жеста в данный момент.

**РИТМ:** чередуй короткие и длинные предложения — как дыхание.
Три одинаковых по длине подряд → переписать.
Союзы Но / А / И в начале предложений — как живая речь, не как правило.

**ВИЗУАЛЬНЫЙ РИТМ:**
Каждые 5–7 абзацев — разделитель:
———————————————
Пауза. Читатель останавливается — и читает дальше.

## ДЕТАЛИ И ОБРАЗЫ

**АНТИШТАМП:** минимум 3 точных детали — таких, которых нет в других историях.

**ПРЕДМЕТ-ЯКОРЬ:** 1–2 предмета. В начале — появляется. В финале — тот же, но с другим смыслом.

**ВИРУСНЫЙ ТРИГГЕР (минимум 1):**
— герой ест и не чувствует вкуса
— никто не смотрит — он знает
— правда сказана — никто не услышал

**БАНК ОБРАЗОВ:**
Физические: влажная квитанция ЖКХ / треснувший ламинат / детский рисунок на холодильнике / аптечный пакет на подоконнике / советский сервиз, который не доставали / фотография без рамки у стены
Поведенческие: гладит скатерть без складок / переставляет солонку / не выключает свет в коридоре / подписывает продукты в холодильнике / перекладывает письмо из стопки в стопку

❌ Запрещены как центральный образ: чайник / кружка / окно / потолок / телефон / тишина / руки / вода / кухня / молчание

## ДИАЛОГИ

Короткие. Без прямых ответов.
Между репликами — пауза / жест / взгляд — каждый в отдельном абзаце.
Диалог показывает конфликт, никогда не объясняет его.

**Русская специфика:**
«Нормально» = плохо → следует абзац с тяжёлым физическим жестом.
«Всё хорошо» = ничего не хорошо → следует абзац с тяжёлым физическим жестом.
«Как скажешь» = никогда не прощу.
«Делай что хочешь» = я уже всё решила.
«Ладно» = закрытая дверь.

**ТЕСТ:** реплику можно отдать другому персонажу? → переписать.

## ЗАПРЕЩЕНО

❌ Клише: ком в горле / разбитое сердце / слёзы покатились / пустота внутри / душа болела / сердце сжалось / мир рухнул
❌ Коммерческие названия: Пятёрочка / Сбербанк / Тинькофф → «магазин у дома» / «зелёный банк»
❌ Хук начинается с места или погоды
❌ Одна конструкция более 2 раз: «она смотрела» / «он стоял»
❌ Мораль в финале: «берегите близких» / «жизнь учит нас»
❌ Объяснять значение детали — только показывать

## МОНЕТИЗАЦИЯ ДЗЕНА

**Запрещено:** детальное описание медпроцедур / актов насилия / физиологии романтики / суицидальных методов.

**Допустимо:**
— «Операция прошла» — называть, не описывать.
— Романтика: слово + одно действие без деталей.
— Насилие: условия, не акты — «она боялась возвращаться домой».
— Смерть: реакция живых, не картина.

## СТРУКТУРА — 6 СЦЕН

**СЦЕНА 1 — ХУК:** конфликт с первых 2 предложений. Читатель не знает что — но уже не уйдёт.

**СЦЕНА 2 — ПРЕЖНЯЯ ЖИЗНЬ:** что было до. Здесь вводится предмет-якорь.

**СЦЕНА 3 — ПЕРВОЕ СОМНЕНИЕ:** деталь без объяснения. Тело знает раньше головы.

**СЦЕНА 4 — СДВИГ:** давление меняется. Появляется выбор.

**СЦЕНА 5 — ПЕРЕЛОМ:** только через тело. Минимум 3 абзаца на главный момент. После — взрыв или полная остановка.

**СЦЕНА 6 — ФИНАЛ:** предмет-якорь возвращается с другим смыслом. Последний абзац — *курсивом*. Последняя строка — удар, не точка.

**ФИНАЛ:**
Вариант 1: вопрос читателю — «А вы бы простили?»
Вариант 2: оборванная фраза без ответа.
Без облегчения. Без авторского резюме.
